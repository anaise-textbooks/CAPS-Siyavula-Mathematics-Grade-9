## Combining like terms in algebraic expressions

### Rearrange terms, then combine like terms

To
        check whether two expressions are possibly equivalent, you can
        evaluate both expressions for several different values of the
        variable.

2. In each case below,
             first predict whether the two expressions are equivalent and
             then check by evaluating both for \(x = 1,~ x = 10,~ x = 2\) and \(x = -2\) in the tables.
   2. \(x(x + 3)\) and \(x^2 + 3\)
   4. \(x(x + 3)\) and \(x^2 + 3x\)

Some expressions can be simplified by
        rearranging the terms and combining "like
        terms".

In the expression \(5x^2 + 13x + 7 + 2x^2 - 8x - 12\), the terms \(5x^2\) and \(2x\) are like
        terms.

<Callout type="note" title="Note">
Two or more like terms can
          be combined to form a single term.
</Callout>

\(5x^2 + 2x^2\) can be replaced by \(7x^2\) because
        for any value of \(x\), for example \(x = 2\) or \(x = 10\), calculating \(5x^2 + 2x^2\) and \(7x^2\) will produce the same output value (try it!).
